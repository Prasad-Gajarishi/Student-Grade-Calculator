# Student-Grade-Calculator

A Python mini-project that calculates a student's overall academic performance.

## Features

- Student name input
- Marks validation (0–100)
- Total marks calculation
- Average marks
- Percentage calculation
- Grade calculation
- Pass/Fail result
- Highest and lowest marks with subject name
- Beautiful report card
- Calculate results for multiple students

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python grade_calculator.py
```
